# 🪑 技能：Bot 圆桌会

> 遇到拿不准的问题，让几个 Bot 从不同角度各说各的，最后由总管拍板，给出一个明确结论。

## 什么时候用
- 有取舍的决策：要不要付费、先做哪个玩法、某个方案值不值
- 单个 Bot 容易"自说自话"的问题

## 角色
| 角色 | 由谁担任 | 职责 |
|---|---|---|
| 价值方 / 提案方 | 玩法教练 | 提出方案，论证为什么值得做，给出可观察的"成功信号" |
| 事实方 / 质疑方 | 研究猿 | 核实事实、找坑和红线，查不到就直说，标注出处 |
| 裁决方 | YOYO 总管 | 综合双方，给出结论、条件和复盘时间 |

## 流程
1. **出题**：总管把问题一次写清楚（背景、约束、要什么形式的回答），同时发给两个 Bot。
2. **各自独立作答**：两个 Bot 互不看对方答案，避免互相带偏；各自只回一次。
3. **裁决**：总管列出双方要点，给出"现在做什么 / 不做什么 / 什么信号出现时改主意"。
4. **落盘**：会议记录存成 `roundtables/<日期>-<主题>.md`。
5. **定复盘**：需要观察数据的结论，设一个一次性提醒到期复盘。

## 省额度规则
- 每个 Bot 只被唤醒一次，不来回辩论
- 题目一次说清，答案限定长度
- 不使用浏览器
